# tictactoe-C
Implementations of tictac in C and object oriented C++.



# Usage:


## 🛠 Build Instructions

### C Version (`tictac.c`)

```bash
gcc -o tictac tictac.c
./tictac
```

### C++ Version (`tictac.cpp`)

```
g++ -std=c++17 -o tictacobj tictacobj.cpp
./tictacobj
```



## Gameplay


 When entering the program you will prompted for the coordinate you wish to place your mark. Enter your input in the form x,y.

## Example:
```
+---+
|   |
|   |
|   |
+---+

X's turn!
1,1
+---+
|   |
|   |
|X  |
+---+
```
